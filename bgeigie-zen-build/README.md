# bGeigie Zen interactive build guide

Static 3D assembly viewer (no build step), modelled on https://aps.chibatech.dev/ii/sesame-build/.

- `js/renderer.js`: WebGPU renderer with WebGL2 fallback. `js/main.js`: UI, timeline, camera. `js/steps.js`: step choreography. `js/i18n.js` + `locales/*.json`: text (EN/JA).
- `assets/assembly.{json,bin}`: geometry, generated by `scripts/build_assembly.py`. **Placeholder primitives**: swap in an exporter for the real CAD, same format.
- `scripts/make_locales.py` regenerates `locales/*.json` (uses `scripts/ref_en.json` for shared UI strings).

Run: `python3 -m http.server` here, then open http://localhost:8000/?step=5 (`&renderer=webgl`, `&lang=ja`, `&style=line` supported).
Deploy: push the folder to GitHub Pages.

Viewer code derives from the APS-II Sesame guide; confirm reuse terms with its author.
